# 🛡️ SmartShield AI

SmartShield AI is a web-based digital safety assistant that helps users detect suspicious messages, emails, and URLs.

The application analyzes user input for suspicious keywords and provides a risk score and risk level.

---

## 🚀 Features

- 👤 User Registration
- 🔐 User Login Authentication
- 🔍 Suspicious Message Analyzer
- 📊 Risk Score Calculation
- 🔴 High Risk Detection
- 🟠 Suspicious Risk Detection
- 🟢 Low Risk Detection
- ⚠️ Suspicious Keyword Detection
- 📜 Analysis History
- 🛡️ Online Safety Tips
- 🚪 User Logout
- 🗄️ SQLite Database

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
